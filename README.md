## 🚀 About Me

I’m an IoT and robotics engineer focused on connecting the physical and digital worlds through automation.
As co-founder of [Branch Robotics](https://www.branchrobotics.tech), I develop modular control systems and smart infrastructure for agriculture and other industrial use cases.
I also lead software and controls engineering at [Aquanzo](https://www.aquanzo.com), where we build scalable, cloud-connected water quality monitoring systems for aquaculture.
My work spans embedded C++ for sensor integration, Python for edge processing, and Google Cloud for storage, analytics, and real-time control.
I specialize in RS485/Modbus communication, edge-to-cloud pipelines, and resilient IoT deployments in challenging environments.
I'm passionate about building practical, elegant solutions that make physical systems smarter and more sustainable.
Always curious, always prototyping.
